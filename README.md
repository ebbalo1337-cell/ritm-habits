# Ритм

Мобильный дневник ежедневных привычек на русском. В разделе «Сегодня» можно добавлять, переименовывать и отмечать привычки. Раздел «Статистика» показывает недельные итоги и серии, позволяет скачать или восстановить резервную копию JSON.

История хранится в localStorage браузера. При смене адреса сайта или устройства экспортируйте данные в старом трекере и импортируйте их в новом. Перед заменой приложение показывает подтверждение.

## Запуск проекта

Используйте Node.js 22.12 или новее. Выполните `npm ci`, затем `npm run dev`. Проверки запускаются командой `npm test`. Команда `npm run build` обновляет готовую статическую версию в папке docs.

## GitHub Pages

Добавьте содержимое проекта в репозиторий. В Settings → Pages выберите Deploy from a branch, ветку main и папку /docs. После сборки закоммитьте обновлённую docs. Маршруты используют hash, чтобы страницу статистики можно было обновить на статическом хостинге.

План пилота, целевая аудитория и гипотеза монетизации описаны в [STARTUP.md](STARTUP.md).
